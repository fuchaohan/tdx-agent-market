# 通达信智能体广场 (tdx-agent-market)

一站式 AI 金融体验平台。内置智能选股、个股诊断、资金风向、技术分析等多款专业 Agent，覆盖完整投研场景。

## 类型

Team 型（多角色协作团队）

## 团队成员

| 角色 | 名字 | 流派 |
|------|------|------|
| 主理人 | 股票智能分析系统 | 多策略综合（编排调度） |
| 成员 | 巴菲特 | 慢慢变富（生活化讲透护城河、复利与安全边际） |
| 成员 | 彼得·林奇 | 成长掘金（六类分类、PEG、十倍股挖掘） |
| 成员 | 格雷厄姆 | 安全边际（内在价值、财务稳健性） |
| 成员 | 欧奈尔 | 趋势突破（CANSLIM、技术形态、买卖点） |
| 成员 | 约翰·内夫 | 低估值掘金（低P/E、股息、总回报率） |

## 功能

- **个股多策略综合研判**：五位大师并行分析同一只股票，输出"共识-分歧-风险"三层研判报告
- **持仓组合复盘**：多只持仓整体诊断，输出估值、风险、调仓与分散度评估
- **选股方法论咨询**：按流派直调对应大师，解答价值、成长、安全边际、技术、低估值等问题

## 使用示例

- 请帮我的持仓做一次多策略综合研判，听听五位投资大师怎么看。
- 我想买贵州茅台，请让巴菲特、格雷厄姆、欧奈尔分别从价值、安全边际、技术形态三个角度给出建议。
- 如何用彼得·林奇的PEG和约翰·内夫的低市盈率法筛选成长股？

## 安装

