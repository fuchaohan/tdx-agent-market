## 教育模块库（格雷厄姆特化）

### Edu-GRA-1: 盈利收益率与债券收益率的比较

```
**盈利收益率 - 格雷厄姆的核心工具**
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

定义：
盈利收益率 = E/P = 1/市盈率(PE)

它告诉你：如果你今天买下整个公司，
每年的投资回报率是多少。

为什么重要？

格雷厄姆的核心原则：
"股票的盈利收益率应该至少是AAA级国债利率的2倍"

为什么是2倍？
• 股票风险 > 债券风险 → 需要风险补偿
• 2倍是格雷厄姆经验总结的安全系数

实战计算：

假设：
• AAA国债利率 = 3%
• A公司 PE=10倍 → 盈利收益率 = 10%
• B公司 PE=30倍 → 盈利收益率 = 3.3%

判断：
• A公司：10% ÷ 3% = 3.3倍 远超2倍标准 → 可能低估
• B公司：3.3% ÷ 3% = 1.1倍 不到2倍 → 不符合格雷厄姆标准

直觉理解：
如果国债给你3%的无风险回报，
股票至少应该给你6%（2×3%）才值得承担额外风险。

注意事项：
• 这是最保守的标准，适合防御型投资者
• 成长股可能不满足此标准但仍可投资（用其他方法评估）
• 利率环境变化时要调整标准
```

### Edu-GRA-2: 净流动资产价值（NCAV）策略

```
**NCAV策略 - "捡烟蒂"投资的精髓**
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

定义：
NCAV = 流动资产 - 总负债

这是公司的"清算价值下限"——
即使公司破产清算，股东理论上能分到的最少金额。

格雷厄姆的NCAV法则：

"买入市值低于NCAV三分之二（2/3）的股票"

为什么？
• 你花0.67元买到了价值1元的资产
• 即使最坏情况（破产），你也有33%的安全垫
• 如果公司继续经营，还有可能获得更多收益

计算示例：

某制造企业资产负债表摘要：
┌─────────────────────┬──────────┐
│ 项目                │ 金额(亿) │
├─────────────────────┼──────────┤
│ 现金及等价物         │ 15       │
│ 应收账款             │ 25       │
│ 存货                 │ 30       │
│ 其他流动资产          │ 5       │
│ ─ 流动资产合计       │ 75       │
│                     │          │
│ 总负债               │ 40       │
│                     │          │
│ NCAV (75-40)         │ 35       │
│ 当前市值              │ 20       │
│ 市值/NCAV            │ 57%      │ ← 小于2/3！
└─────────────────────┴──────────┘

判断：
市值(20亿) < NCAV(35亿) × 2/3 ≈ 23.3亿 → 符合格雷厄姆标准！

现代市场适用性：
• 这种极端低估的机会在现代A股市场很少见
• 但原理依然有效：寻找市值显著低于资产价值的标的
• 变体：P/B<1 的低估值策略

经典案例：
• 1970年代的格雷厄姆大量持有这类"烟蒂股"
• 年化回报约20%，远超标普500
• 巴菲特早期也采用此策略
```
