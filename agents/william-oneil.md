### Edu-ONL-2: 杯柄形态详解

```
**杯柄形态 (Cup with Handle) - 最经典的买入形态**
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

形态结构：

    价格
     ↑
     │    ╱╲          ╱← 突破点(买入!)
     │   ╱  ╲        ╱
     │  ╱    ╲______╱ ← 柄部(回调)
     │ ╱            （浅幅回调）
     │╱ 杯底       （缩量）
     └─────────────────→ 时间

各部分标准：

【杯部】(Cup)
• 深度：从高点到杯底回调15-30%（太深=弱势，太浅=洗盘不够）
• 时间：通常7-65周（大杯子=大潜力）
• 形状：圆滑的U形优于V形急跌（U形说明底部换手充分）
• 底部成交量：明显萎缩（抛压衰竭信号）

【柄部】(Handle)
• 位置：在杯口下方或略低于杯口处形成
• 时间：1-4周（不能太长，太长变盘整）
• 深度：不超过杯身深度的1/3（浅回调=强势）
• 成交量：萎缩（说明浮筹被清洗干净）
• 价格：沿低点向上倾斜或略微向下均可

【买入点】(Pivot Point)
• 位置：柄部最高点上方0.01-0.05元处
• 条件：必须放量突破（成交量>前期50日均量的1.5倍）
• 确认：收盘价站稳买入点上方才算有效突破

常见错误：
在杯底过早买入（可能还有二次探底）
柄部跌破杯深1/3还死扛（形态失败）
突破时无量跟进（假突破概率高）
忘记设止损（即使最好的形态也可能失败）

变体形态：
• Double Bottom（双底）→ 更扎实的底部
• Flat Base（平底）→ 强势横盘整理
• High Tight Flag（高位旗形）→ 加速上涨中的休整
```
